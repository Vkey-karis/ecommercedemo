# KINETICS — High-End Minimalist Fashion E-Commerce

A clean, minimalist, high-converting e-commerce fashion portfolio demo built with **React**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

## Features Included

- **Sticky Navigation**:
  - Pure white background with subtle border (`border-b border-gray-200`)
  - Bold text logo `KINETICS`
  - Navigation links: `Men`, `Women`, `Accessories`, and `Sale` (styled in signature red)
  - Search, Wishlist, User Account, and Cart icon with a tiny black notification badge (`2`)
  - Mobile responsive drawer menu
- **Hero Section**:
  - Split grid layout (`grid md:grid-cols-2`)
  - Small pill tag: `NEW COLLECTION`
  - H1: `Elevate Your Everyday Style.`
  - Subheadline: `Discover premium menswear and womenswear designed for the modern aesthetic.`
  - High-converting CTA: `Shop Now` with smooth scroll to collections
  - Editorial high-fashion Unsplash image with floating capsule badge
- **Our Collections (Product Grid)**:
  - 8 curated editorial fashion products (`grid-cols-2 md:grid-cols-4 gap-6`)
  - Tiny `NEW` and `-20%` badges in the top left corner
  - Product titles and localized pricing in **KSh** (Kenyan Shillings)
  - Hover-activated **Add to Cart** button with instant feedback
  - Category filters: All Pieces, Men, Women, Accessories, Sale
  - Wishlist toggle capability with live badge counter
- **Interactive Cart & M-Pesa Checkout Drawer**:
  - Slide-out cart displaying bag items, quantities, subtotal, and Nairobi delivery calculation
  - One-click Safaricom M-Pesa STK push simulation
- **Value Proposition Section**:
  - 3 clean columns below collections:
    1. `Free Delivery in Nairobi` (`Truck` icon)
    2. `Secure M-Pesa Payments` (`ShieldCheck` icon)
    3. `Easy Returns within 14 Days` (`RotateCcw` icon)
- **Minimalist Footer**:
  - Clean links for Shipping Policy, Returns, Contact, and Size Guide modals
  - Newsletter VIP subscription
  - `© 2024 KINETICS. All rights reserved.`
- **Floating WhatsApp Button**:
  - Fixed bottom-right corner in WhatsApp green with `Need help? Chat with us`

## Getting Started

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
